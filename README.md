# EduChain: Blockchain-Based Student Crowdfunding

A secure, transparent, and decentralized crowdfunding platform tailored for education. This project bridges the gap between students seeking educational loans and lenders willing to fund them. By leveraging blockchain concepts (like cryptographic hashing) for record-keeping, the platform ensures that transactions, student verifications, and loan disbursements are immutable and trustworthy.

## 🌟 Key Features
* **Role-Based Portals:** Dedicated dashboards for Students, Lenders, and Administrators.
* **Student Dashboard:** Students can register, upload identity documents, and post their education loan requests.
* **Lender Dashboard:** Lenders can browse through verified student profiles and fund requested loans securely.
* **Admin Verification:** Administrators review uploaded documents, verify student credentials, and oversee platform activity.
* **Blockchain Security:** Utilizes cryptographic hashing utilities to secure transaction data and ensure tamper-proof loan records.
* **Loan Lifecycle Management:** Complete flow from posting a loan, funding it, to tracking repayments.

## 💻 Tech Stack
* **Backend:** Java (Servlets, JSP), JDBC
* **Frontend:** HTML, CSS, JavaScript, Bootstrap (Matrix Admin Theme)
* **Database:** MySQL 
* **Security:** Blockchain Hashing / Cryptography

## 🚀 Getting Started
1. Import the `educhain_db.sql` file into your MySQL database.
2. Deploy the project on an Apache Tomcat Server using your preferred Java IDE (Eclipse/IntelliJ).
3. Access the application via the local server port.
